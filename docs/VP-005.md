# VP-005 — Source-defined neural expert Grounds across replaceable observer-hosts

**Status:** experimental; synthetic exact-math reference, E-CPU-native execution, and multi-job GitHub-host verification are distinct evidence gates. Stacks on VP-004 → VP-003 → VP-002; keep draft until exact-HEAD native CI passes.

## Why this experiment

E-CPU began as MailCPU's communication-state virtual machine (Oct 2026). Later evolution includes navigable laws (`lcg_navigate`), observer-hosts, E-CPU native Hypervisor/Virtual Layer operators, persistent computational sessions, and source-addressed model parameter Grounds (MWS-001/002, HFG-001/002). VP-003 already performs **real parameter-backed sparse SwiGLU**; VP-004 makes Ground navigation a causal predecessor of a neural operator. None of those things requires the model's *identity* to equal one machine's RAM image.

This experiment asks a stricter **special-case** question: Can a sparse neural Ground describe vastly more experts than a receiver can materialize, yet select an exact bounded expert frontier at an arbitrary logical token coordinate **without scanning all experts**, then realize that frontier on an ephemeral, separately authorized E-CPU observer-host?

## Scoped model mathematics

`ExpertGround(expert_count=N, top_k=k, hidden_dim=d, intermediate_dim=h)` with power-of-two N, k ≤ 16. The model is fully **procedural and synthetic**:

- Logical coordinate `t` selects a router center `c_t = lcg_navigate(5,1,N,7,t)`. Because 5 ≡ 1 mod 4, the increment is odd, and N=2^r, the orbit has full period N.
- Experts `j∈[0,N)` have declared router score `s_j=−(j−c_t)^2` and deterministic ascending-index tie-breaking. The *top k* are the k nearest indices to the center. This can be selected by an O(k) two-sided frontier, *without enumerating N scores*. The native path explicitly checks E-CPU's existing `law_certifier.lcg_navigate` against a separately implemented binary affine composition.
- Each expert has exactly `3*d*h` signed integer gate/up/down parameters, generated by one fully declared, indexed arithmetic law. The gate computes a **ReLU-gated product**, and down projection sums selected intermediate activations. Aggregate weights are exact normalized `1/(1+|j−c|)` rationals, **not Qwen softmax**.
- The selected k experts execute real gated neural arithmetic (no simulation of a larger trained model); a separately written scalar oracle independently checks every output coordinate. Missing/forged source identities, malformed routes, altered results, noncanonical rationals, or unadmitted model types must refuse.

At N=2^48, d=3, h=4, the Ground describes `3*N*d*h = 10,133,099,161,583,104` logical expert parameters. A single query materializes **eight** experts, not 2^48. This is an exact description of a highly structured model family, **not** storage/reconstruction of 10 quadrillion independently trained values. The data-processing costs of each demanded expert still exist.

## Native observer-host handoff

The **planner** records only a typed model intention and algebraically justified selected frontier. The **receiver** uses the existing `NativeInferenceHost` (VP-003), which delegates to actual E-CPU `HeadlessOS`, `VirtualLayerRuntime`, `OperatorSpec`, its Hypervisor's local capability gate, and retained native operator receipt. The receiver recomputes the plan from its *locally pinned model Ground* rather than accepting caller-proposed weights, code or grants.

A **third verifier** independently re-evaluates the selected neural arithmetic and refuses altered/rehashed observations. The GitHub workflow uses separate jobs and artifacts to transfer the finite plan and result, showing a disposable observer-host workflow across an existing HTTPS/GitHub communication substrate. GitHub jobs are active conventional realizers; the workflow does **not** prove that TLS, GitHub storage or a passive TCP router performed the gated neural multiplications. Artifacts are evidence/transport, not automatic authority.

## Reproduction

```bash
python -m unittest discover -s tests -p 'test_navigable_experts.py' -v
python -m vp.navigable_experts plan --out /tmp/plan.json
# Get expected model Ground from planner's pinned policy, not a request-defined digest.
python -m vp.navigable_experts execute --plan /tmp/plan.json --out /tmp/report.json --expected-ground <trusted-fingerprint>
python -m vp.navigable_experts verify --report /tmp/report.json --expected-ground <trusted-fingerprint>
```

The GitHub workflow requires native E-CPU installed at the pinned main revision, and exchanges the plan/result as workflow artifacts **between different jobs**. Its verifier also checks explicit refusal cases. CI remains a separate gate; local standard-library tests alone cannot certify native execution.

## Next invariants toward real arbitrary pretrained models

1. A model identity has an exact source snapshot (`ModelParameterSpace` + MWS-001/002), whose expert tensors are *actually present or reconstructible* under admitted evidence; do not substitute this procedural ground for pretrained Qwen bytes.
2. Router semantics are proved for the target model. Qwen3's actual router requires top-k after evaluating scores from its real router matrix; this synthetic nearest-center rule is not interchangeable. If no closed-form selection proof exists, navigate the admitted DAG to perform the required routing computation.
3. Replace local selected-expert arithmetic with an evidence-qualified transport/path realization when measured; preserve receiver-owned authority, source digests, input/output receipts and independent verification.
4. Connect actual model-layer predecessor outputs, attention/KV state and tokenizer identity across separate observer-host lives using E-CPU M3 quorum state rather than the same Python model object.

The architecture is **not hardware-specific**. This does not assert computation without any physical resource or that arbitrary pretrained, high-entropy weights can be derived from a hash. Those remain open research goals governed by explicit evidence.
